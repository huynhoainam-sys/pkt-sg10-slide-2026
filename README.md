# PKT SG10 — Họp tháng 10/2026

Website trình chiếu 8 slide HTML cho cuộc họp PKT SG10, có popup thống kê PTTB, Kickoff và CLDV.

## Triển khai

1. Tải `Hop_PKT_Thang_10_2026_Studio_Dashboard_V20.html` từ cuộc trò chuyện.
2. Trong repository này chọn **Add file → Upload files**, đổi tên file thành **`index.html`** trước khi tải lên.
3. Tại **Settings → Pages → Build and deployment**, chọn **Deploy from a branch**, branch `main`, folder `/ (root)` và **Save**.
4. Website dự kiến: https://huynhoainam-sys.github.io/pkt-sg10-slide-2026/

> **Chú ý:** Repository đang ở chế độ công khai. File HTML chứa số liệu nội bộ; cần cân nhắc quyền chia sẻ trước khi tải lên.
